# CMU Maps

## Overview

[CMU Maps](https://cmumaps.com) is a web application that provides a map of the Carnegie Mellon University campus, allowing users to easily access information about campus locations.

Key features include:

- View floorplans
- Room level navigation
- Search for buildings and rooms
- View building and room information
