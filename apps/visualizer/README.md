# CMU Maps Visualizer

## Overview

The CMU Maps visualizer, served at `/visualizer` on [cmumaps.com](https://cmumaps.com), is a tool to help visualize the CMU Maps data.

## Development

### Running the Visualizer

Start the server, both UIs and their dependencies from the repository root inside `nix develop`:

```zsh
pitchfork start --local
```

The visualizer runs at <http://localhost:5174/visualizer/>.
